# Сайт помощи при ДТП с Telegram ботом

Проект представляет собой веб-сайт на Django с интегрированным Telegram ботом для рассылки новостей и модерации контента.

## Описание проекта

### Веб-сайт
- Новостной раздел с комментариями
- Система отзывов
- Разделы: Аварийный комиссар, Независимая экспертиза, Автоюрист
- Административная панель для управления контентом

### Telegram бот
- Рассылка новых публикаций подписчикам
- Модерация отзывов и комментариев
- Создание новостей с изображениями
- Интерактивный интерфейс с inline кнопками

## Пошаговая инструкция по установке

### 1. Клонирование репозитория
```bash
# Клонируем репозиторий
git clone https://github.com/your-username/accident-help.git
cd accident-help
```

### 2. Настройка виртуального окружения
```bash
# Создаем виртуальное окружение
python -m venv venv

# Активируем виртуальное окружение
# Для Linux/macOS:
source venv/bin/activate
# Для Windows:
venv\Scripts\activate

# Устанавливаем зависимости Django проекта
pip install -r requirements.txt

# Устанавливаем бота
cd tgbot
pip install -e .
cd ..
```

### 3. Настройка переменных окружения

1. Создайте файл `.env` в корневой директории проекта:
```env
# Django settings
SECRET_KEY=your-django-secret-key
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
```

2. Создайте файл `.env` в директории `tgbot`:
```env
# Telegram Bot settings
BOT_TOKEN=your_bot_token_here        # Получить у @BotFather
ADMIN_IDS=123456789,987654321        # ID администраторов через запятую
BASE_URL=http://localhost:8000        # URL вашего сайта
```

### 4. Настройка базы данных
```bash
# Применяем миграции
python manage.py migrate

# Создаем суперпользователя Django
python manage.py createsuperuser
```

### 5. Создание необходимых директорий
```bash
# Создаем директории для медиафайлов
mkdir -p media/news_images
mkdir -p static/img
```

### 6. Сбор статических файлов
```bash
python manage.py collectstatic
```

## Запуск проекта

### Вариант 1: Запуск всего проекта одной командой
```bash
# Запускает и Django сервер, и Telegram бота
python run.py
```

### Вариант 2: Раздельный запуск
```bash
# В первом терминале запускаем Django
python manage.py runserver

# Во втором терминале запускаем бота
python manage.py runbot
```

### Вариант 3: Запуск только бота
```bash
cd tgbot
source venv/bin/activate  # или venv\Scripts\activate для Windows
python run_bot.py
```

## Проверка работы

### 1. Веб-сайт

- Админ-панель доступна по адресу http://localhost:8000/admin

## Примечания и устранение проблем

### Настройка изображений
1. Убедитесь, что в settings.py правильно настроены пути:
```python
MEDIA_URL = "media/"
MEDIA_ROOT = BASE_DIR / "media"
```

2. Добавьте обработку медиа-файлов в urls.py:
```python
from django.conf import settings
from django.conf.urls.static import static

urlpatterns = [
    # ... ваши URL паттерны ...
] + static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
```

3. Проверьте права доступа:
```bash
# Создайте директории если их нет
mkdir -p media/news_images
# Установите правильные права
chmod -R 755 media
```

### Решение проблем с ботом
1. Если бот не отвечает:
- Проверьте токен в tgbot/.env
- Убедитесь, что бот запущен (python manage.py runbot)
- Проверьте логи на наличие ошибок

2. Если изображения не загружаются:
- Проверьте BASE_URL в tgbot/.env
- Убедитесь, что Django сервер доступен по этому URL
- Проверьте права на запись в media/news_images

3. Если не работает админка бота:
- Проверьте ID администраторов в ADMIN_IDS
- Используйте @userinfobot чтобы узнать свой ID
- Формат: ADMIN_IDS=123456789,987654321 (без пробелов)

### Переустановка после изменений
Если вы внесли изменения в код бота:
```bash
cd tgbot
./reinstall.sh
```

### Проверка работы
1. Веб-сайт:
```bash
python manage.py runserver
# Откройте http://localhost:8000
```

2. Бот:
```bash
python manage.py runbot
# Отправьте /start боту в Telegram
```

3. Тестирование загрузки изображений:
- Создайте новость через админ-панель с изображением
- Проверьте отображение на сайте
- Проверьте отправку через бота

## Поддержка
При возникновении проблем:
1. Проверьте правильность всех настроек в файлах .env
2. Убедитесь, что все зависимости установлены
3. Проверьте права доступа к директориям media и static
4. Просмотрите логи Django и бота для поиска ошибок
